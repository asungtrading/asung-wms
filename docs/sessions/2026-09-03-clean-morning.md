## 3. `ledger_collected_at` — WMS 요청 처리

화면의 주인공 열이 `ledger_qty` 인데 **그 값이 어디까지 반영된 것인지**를 보여줄 수 없었다.
`snapshot_at` 은 Cin7 시각이고 `checked_on` 은 일지 시각이라 **둘 다 원장 수집 시각이 아니다.**

⚠️ **화면이 `inv_sync_state` 를 직접 읽지 않는다** — 계약에 없는 테이블은 원장이 바꿔도
WMS 에 통보되지 않는다. **근거가 실사고다**: 2026-09-01 에 WMS 의 `⟳ Stock` 체인이
**12일간 죽어 있었는데 어느 화면에도 드러나지 않았다.**

- `inv_diff_summary()` · `inv_stock_master(...)` 둘 다 **`ledger_collected_at` ·
  `ledger_lag_source`** 를 낸다
- ⭐ **`last_ok_at` 을 쓴다.** 지시서는 「`last_run_at` 일 것」이라 추정했는데
  **둘 다 실재했고 성공 축이 맞다** — 실패한 회차 시각을 신선도로 보여주면 안 된다
  📌 **확인 지시가 값을 했다.** 추측대로 갔으면 틀린 축을 썼다
- ⚠️ **`cost` 제외**: 하루 1회(00:33)라 `min` 에 넣으면 **늘 「하루 뒤처짐」**으로 보이고
  **원가 축이라 재고 수량과 무관**하다. 코드에 목록을 박지 않고 `source_key <> 'cost'` 로 거른다

**✅ 실물**

```
ledger_collected_at   2026-09-03 07:11:48 (토론토) = adjustment 의 last_ok
ledger_lag_source     adjustment
여섯 축 범위          07:11 ~ 07:34   ⇒ 가장 뒤처진 것이 23분
```

📌 `adjustment`·`assembly` 가 뒤인 것은 **시간당 1회**라 정상이다.

### ⚠️ 「조건만 완화」로는 안 된다

```

```

⇒ **`last_modified_on` 이 `inv_missing_lines` 유니크 키의 일부**다. 「같은 편집의 재검출은
do-nothing」으로 **중복 폭주를 막는 장치**다.

⚠️ 값 없이 표에 넣으면 **매 회차 같은 행이 쌓여 회차 캡 500 을 소진하고 진짜 소멸을 가린다**
— 2026-08-31 에 겪은 사고와 같은 모양이다.
📌 **G4 주석의 「키가 무너진다」는 옳은 판단이었다.** 내 첫 추정(조건만 완화)이 얕았다.

### 처방 — 판정은 하되 표에 넣지 않는다

```
지금     lmo 없음 → 판정 자체를 건너뛴다      → 아무것도 모른다
1단계    ⭐ 판정은 한다 → 표에는 안 넣는다    → 회차 로그에 남는다
```

- `MissingDocCheck.lmo` 를 `string | null` 로. ②-a 는 `lmoRaw` 가 비어도 후보에 넣는다
- 판정 루프에서 ⚠️ **`partitionBinChanged` 뒤 · 캡 앞**에 분기 — bin 변경분은 소멸이 아니다
- 응답 넷: `missing_lines_unkeyed` · `_docs`(≤20) · `_sample`(≤200) · `_truncated`
  ⭐ **`_sample` 이 이 처방의 실질**이다 — 목록이 없으면 사람이 상쇄를 못 만든다.
  `inv_collect_runs.summary` 에 자동으로 실려 **SQL 로 조회**된다
- ⚠️ **카운터를 섞지 않았다**: `detected` 는 표에 넣은 것만 · `skipped_no_lmo` 는 그대로.
  아침 점검이 그 구분에 기댄다
- G1·G2·G3 무접촉 — 회차 중단이면 종전대로 소스 전체를 건너뛴다. **그 안전장치가 전제다**

⚠️ **기존 테스트 2개도 고쳤다**(Claude Code 판단):
`missing` 하네스에 새 상수 2개 추출 추가(없으면 `ReferenceError`) ·
`recheck-window` 의 버전 **정확 pin 을 하한으로**(지시한 버전 bump 자체가 그 테스트를
깨는 구조였다). 📌 다른 테스트는 정규식이라 무관하다.

### ⬜ 2단계 (미착수)

표에 기록하려면 **콘텐츠 지문**이 필요하다 — `lmo` 자리에 **A 집합 키의 해시**를 넣어
「내용이 그대로면 같은 지문 → do-nothing」으로 만든다.
⚠️ **마이그레이션(컬럼 추가 + 유니크 재생성)이 필요하고 위험**하다.
⇒ **1단계로 실물을 보고 판단한다.**
