### A-2. ⭐ `FG-00140` — VOID 후 `FG-00141` 로 재작성 · 같은 `line_ref`

[실측 09-29] `FG-00140` 은 VOID 후 `FG-00141` 로 재작성됐고, ⚠️ **다섯 `line_ref` 가 완전히 동일**했다.

⚠️ **[문서화 시 대조]** 지시서는 이것을 「다섯 line GUID 가 동일」한 **특이점**으로 적었다. 그런데 스킬의 확정 사실은 **조립의 `line_ref` = `ProductID`** 다(`description` · 09-04 정정 ④ — `FG-00130`·`FG-00131`·`FG-00132` 가 같은 GUID 다섯).

⚠️ 09-04 에 같은 GUID 를 「재생성 짝의 지문」으로 단정해 커밋했다가 정정한 전례가 있다 — 다시 지문으로 쓰지 않는다.
